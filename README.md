# Retail-e-commerce---DADE
Ce projet demande de concevoir et de développer, une plateforme data E2E pour un acteur du retail, en mobilisant les compétences des 4 modules du Bloc 1 Fond. tech : Data Storage Systems (SQL &amp; NoSQL), Enterprise Data Lakes &amp; Lakehouse Foundations, Scalable Data Platforms &amp; API Engineering, et Real-Time Data Engineering &amp; Distributed Processing.
